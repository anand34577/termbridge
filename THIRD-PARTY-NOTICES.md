they are compiled as published on crates.io. This file records the licences

## What this project relies on

The dependency tree contains no GPL, AGPL, LGPL-only, SSPL or other strong
copyleft code. Every crate is used under a permissive licence: MIT,
Apache-2.0, BSD-2-Clause, BSD-3-Clause, ISC, Zlib, BSL-1.0, Unicode, or a
disjunction that includes one of these. Where a crate offered a choice, this
project takes the permissive option.

Two crates are MPL-2.0, which is weak copyleft at the file level:

- `serialport` — the serial port backend
- `option-ext` — a small extension trait

MPL-2.0 permits use in a larger work under any licence, provided the MPL
source files themselves stay under MPL-2.0 and are made available. Both are
used unmodified from crates.io, so their source is already published. No
notice beyond this file is required, and no MPL code is copied into this
repository.

## Regenerating this audit

```bash
cargo metadata --format-version 1 --all-features > meta.json
cargo audit
```

`cargo audit` checks the pinned versions against the RustSec advisory
database. Run it before each release.
