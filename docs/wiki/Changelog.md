# Changelog

The short version of each release. Full details are in [CHANGELOG.md](https://github.com/anand34577/serial-mcp/blob/main/CHANGELOG.md).

## 0.1.0 (17 November 2026)

First release.

- Serial, TCP client, TCP server and UDP sessions, plus UDP discovery
- Desktop app with validated connection forms, live metrics and activity lights, a filterable text/hex/decimal terminal, macros, repeat and file sending
- Terminal UI with mouse and touch, five themes, file sending, and automatic colour and character detection for any terminal
- MCP server over stdio and HTTP with 24 tools
- Recording to text, CSV or raw files
- Auto-reply rules for device simulation
- Checksums (CRC-16 Modbus/CCITT/XMODEM, CRC-32, LRC, XOR, SUM-8) and a data converter
- Headless commands for scripts
- Builds for Windows, macOS and Linux on x86_64 and ARM
